# Trigger Highlight — подсветка слов-триггеров в чате (GTA:SA / SA-MP, Arizona RP)

Lua-скрипт для **MoonLoader**: перехватывает сообщения чата до их отображения и
подсвечивает те, в которых есть слово из вашего списка. Рядом выводится ник и ID
автора, а одной командой ID копируется в буфер обмена — быстро выдаёте наказание.

## Требования

1. **MoonLoader** (папка `moonloader` в папке игры)
2. **SAMP.Lua** — библиотека событий:
   скачайте архив [THE-FYP/SAMP.Lua](https://github.com/THE-FYP/SAMP.Lua) и
   скопируйте папку `samp` внутрь `moonloader/lib/`
   (итог: `moonloader/lib/samp/events.lua`)
3. Для строковых уведомлений в чат желательен **SAMPFUNCS** (стандартная связка
   SAMPFUNCS + MoonLoader). Без него уведомления пойдут в консоль, подсветка
   сообщений всё равно работает.

## Установка

1. Положите `trigger_highlight.lua` в папку `moonloader/`
2. Запустите игру — при первом запуске создастся файл
   `moonloader/trigger_words.txt`
3. Откройте его и оставьте нужные слова (по одному на строку, `#` — комментарий)

## Слова-триггеры

```
# пример
реклама
discord.gg
оскорбление
```

Поиск устойчив к распространённым обходам:

- регистр не важен: `РЕКЛАМА` = `реклама`
- пробелы и знаки внутри: `р е к л а м а!!!`, `реклама.` — сработает
- латиница вместо кириллицы: `pеклама`, `нahi` — сработает
- цветовые коды `{FFFFFF}` игнорируются

Кодировка: файл слов и скрипт — обычный UTF-8. Чат SA-MP работает
в CP1251, скрипт автоматически конвертирует входящие сообщения,
команды и свой вывод в чат — ничего настраивать не нужно.

## Команды (локальные, на сервер не отправляются)

| Команда        | Действие                                            |
|----------------|-----------------------------------------------------|
| `/trig`        | включить/выключить подсветку                        |
| `/trigadd X`   | добавить слово (можно фразу) и сохранить в файл     |
| `/trigdel X`   | удалить слово                                       |
| `/triglist`    | показать список слов                                |
| `/trigid`      | скопировать ID последнего нарушителя в буфер        |
| `/triglog`     | последние срабатывания (время, автор, ID, текст)     |
| `/trigclear`   | очистить журнал                                     |

## Как выглядит

```
[!] {текст сообщения целиком красным}
[ТРИГГЕР] слово: реклама | автор: Пётр[77] | /trigid - копировать ID
```

Дальше: `/trigid` → ID в буфере → вставляете в команду наказания вашего сервера.

## Настройка (в начале файла скрипта, `cfg`)

- `enabled` — включать ли подсветку при старте
- `marker` — метка перед сообщением (по умолчанию `[!]`)
- `bodyColor` — цвет подсветки текста
- `notify` — показывать ли строку-уведомление с деталями
- `remember` — сколько срабатываний помнит журнал

## Важно

- Скрипт только **читает** входящий чат и ничего не отправляет от вашего имени.
- Использование сторонних скриптов может нарушать правила сервера — сверьтесь
  с правилами Arizona RP перед применением.
