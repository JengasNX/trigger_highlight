# Trigger Highlight — подсветка слов-триггеров в чате (GTA:SA / SA-MP, Arizona RP)

Lua-скрипт для **MoonLoader**: перехватывает сообщения чата до их отображения и
подсвечивает те, в которых есть слово из вашего списка. Рядом выводится ник и ID
автора, а ID одной кнопкой копируется в буфер обмена — быстро выдаёте наказание.

Все настройки — в красивом **игровом меню** (`/trig`), никаких команд настройки.

## Требования

1. **MoonLoader** (папка `moonloader` в папке игры)
2. **SAMP.Lua** — библиотека событий:
   скачайте архив [THE-FYP/SAMP.Lua](https://github.com/THE-FYP/SAMP.Lua) и
   скопируйте папку `samp` внутрь `moonloader/lib/`
   (итог: `moonloader/lib/samp/events.lua`)
3. **mimgui** — графическое меню:
   скачайте релиз [THE-FYP/mimgui](https://github.com/THE-FYP/mimgui) и положите
   папку `mimgui` внутрь `moonloader/lib/`
   (итог: `moonloader/lib/mimgui/init.lua`). Без mimgui скрипт работает в
   упрощённом режиме запасных команд (см. ниже).
4. Для строковых уведомлений в чат желательен **SAMPFUNCS** (стандартная связка
   SAMPFUNCS + MoonLoader). Без него уведомления пойдут в консоль, подсветка
   сообщений всё равно работает.

## Установка

1. Положите `trigger_highlight.lua` в папку `moonloader/`
2. Запустите игру — при первом запуске создадутся
   `moonloader/trigger_words.txt` (слова) и
   `moonloader/config/trigger_highlight.ini` (настройки)
3. Откройте меню командой `/trig` и добавьте нужные слова прямо в нём

## Меню (`/trig`, ESC — закрыть)

Две колонки и панель настроек:

- **Слова-триггеры** — список, поле ввода, добавление и удаление в один клик;
  изменения сразу сохраняются в `trigger_words.txt`
- **Журнал** — время, автор `Ник[ID]`, слово и текст срабатывания; кнопки
  «Скопировать ID», «Ник», «Очистить» (буфер обмена → вставляете в команду
  наказания вашего сервера)
- **Настройки** — вкл/выкл подсветку, уведомления, глубину памяти журнала,
  цвет метки и цвет подсветки (палитра ImGui); всё пишется в
  `config/trigger_highlight.ini` и применяется сразу

Курсор и игрок освобождаются автоматически, пока меню открыто.

## Слова-триггеры

```
# пример
реклама
discord.gg
оскорбление
```

Поиск устойчив к распространённым обходам:

- регистр не важен: `РЕКЛАМА` = `реклама`
- пробелы и знаки внутри: `р е к л а м а!!!`, `реклама.` — сработает
- латиница вместо кириллицы: `pеклама`, `нahi` — сработает
- цветовые коды `{FFFFFF}` игнорируются

Кодировка: файл слов и скрипт — обычный UTF-8. Чат SA-MP работает
в CP1251, скрипт автоматически конвертирует входящие сообщения,
команды и свой вывод в чат — ничего настраивать не нужно.

## Команды

| Команда | Действие                              |
|---------|---------------------------------------|
| `/trig` | открыть/закрыть меню (ESC тоже закрывает) |

Команд настройки больше нет — слова, журнал и цвета живут в меню.

*Без установленного mimgui* доступны запасные команды (все локальные,
на сервер не отправляются): `/trigadd X`, `/trigdel X`, `/triglist`,
`/trigid`, `/triglog`, `/trigclear` — те же функции текстом.

## Как выглядит

```
[!] {текст сообщения целиком красным}
[ТРИГГЕР] слово: реклама | автор: Пётр[77] | /trig — меню
```

Дальше: `/trig` → в журнале «Скопировать ID» → вставляете в команду наказания.

## Важно

- Скрипт только **читает** входящий чат и ничего не отправляет от вашего имени.
- Использование сторонних скриптов может нарушать правила сервера — сверьтесь
  с правилами Arizona RP перед применением.
